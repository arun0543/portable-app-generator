# Portable App Generator (PAG)

Portable App Generator is a documentation-first framework designed for the robust orchestration and generation of portable applications.

## Requirements

- Bash 5.x or higher
- Standard Unix utilities

## Directory Structure

- `assets/` - Static assets used by the generator.
- `docs/` - Project documentation.
- `instances/` - Generated application instances.
- `lib/` - Core bash library modules.
- `logs/` - Execution logs.
- `plugins/` - Extensible plugin modules.
- `templates/` - Application templates.
- `tests/` - Automated test suites.
- `tools/` - Development and maintenance scripts.

## Installation

Run the install script:

```bash
./install.sh
```

## Usage

Run the generator script for usage information:

```bash
./generator.sh --help
```
