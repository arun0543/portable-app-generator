## Future Milestones

### Enterprise
Support for enterprise deployment architectures, LDAP integration, and organizational policies.

### Windows/macOS
Extend the distribution engine to output MSI/EXE for Windows and DMG/PKG for macOS.

### Supply Chain Security
Implement SLSA compliance, SBOM generation, and reproducible build verification.

### Plugin Marketplace Federation
Support resolving plugins across multiple remote, private, and peer-to-peer repositories.

### Remote Repositories
Integrate with OCI registries for distributing plugins and templates.

### Telemetry (Optional)
Opt-in anonymous analytics for command usage, build times, and failure rates.

### Cloud Build
Headless remote build execution integrated with major CI/CD providers.
