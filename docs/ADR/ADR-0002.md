# ADR-0002

# XDG Isolation Strategy

Status

Accepted

---

# Context

Electron applications often store runtime data inside

~/.config

~/.cache

~/.local/share

Sharing these directories causes multiple generated applications to interfere with each other.

---

# Decision

Every generated application receives its own runtime environment.

Override

HOME

XDG_CONFIG_HOME

XDG_CACHE_HOME

XDG_DATA_HOME

XDG_STATE_HOME

TMPDIR

When supported

--user-data-dir

---

# Alternatives

Shared Profile

Rejected

Reason

Instances are no longer independent.

---

# Consequences

Applications behave as separate installations.

Logins remain isolated.

Settings remain isolated.

Cache remains isolated.
