# ADR-0003

# Plugin Architecture

Status

Accepted

---

# Context

Different applications require different cloning logic.

Hardcoding Antigravity support would prevent future growth.

---

# Decision

Introduce plugins.

Each plugin exposes a standard interface.

detect()

clone()

configure()

launch()

verify()

update()

remove()

---

# Consequences

The generator remains generic.

Adding support for a new application requires only a new plugin.

Core code remains unchanged.
