# Architecture Decision Records

This directory contains all architectural decisions made during the development of Portable App Generator (PAG).

The project follows the Architecture Decision Record (ADR) pattern.

Each ADR describes:

- Context
- Problem
- Decision
- Alternatives
- Consequences
- Status
