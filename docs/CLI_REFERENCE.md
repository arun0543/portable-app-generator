# CLI Reference

The `pag` CLI allows you to execute commands via a modular registry system.

## Global Options
- `-v, --verbose`: Enable debug logging.
- `-h, --help`: Show help text.

## Commands

- `pag init`: Initialize a new project or workspace.
- `pag build`: Build the current project.
- `pag validate`: Validate the configuration or project structure.
- `pag install`: Install dependencies and plugins from the marketplace.
- `pag export`: Export a finalized application.

*For more details on any command, run `pag <command> --help`.*
