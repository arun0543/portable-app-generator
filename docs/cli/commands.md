# PAG CLI Reference

## Available Commands

* `pag init`
* `pag new`
* `pag build`
* `pag validate`
* `pag export`
* `pag install`
* `pag remove`
* `pag list`
* `pag info`
* `pag doctor`

* `pag plugin`
* `pag template`

## Global Options

* `--help, -h`: Show help
* `--verbose, -v`: Enable verbose logging
* `--version, -V`: Show version
