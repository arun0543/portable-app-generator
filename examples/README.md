# PAG Examples

This directory contains several runnable example projects generated by the Portable App Generator (PAG).

## Applications
- **`simple-app`**: A basic shell application structure.
- **`node-app`**: An application structure intended for NodeJS packaging.
- **`electron-app`**: An application structure intended for Electron packaging.
- **`python-app`**: An application structure intended for Python packaging.

## Extensions
- **`plugin-example`**: A scaffolded PAG plugin for extending CLI and build capabilities.
- **`template-example`**: A scaffolded PAG template for new project generation.

## Usage
You can validate, build, or export any of these examples using the PAG CLI:

```bash
pag validate examples/simple-app
pag build examples/simple-app
pag export examples/simple-app simple-app.tar.gz
```
